### ⚡ Edge AI

Отдельно интересует запуск нейронных сетей **не в облаке, а непосредственно на конечном устройстве**.

Работаю с задачами, где необходимо учитывать:

* ограниченный объём RAM и VRAM;
* производительность CPU/GPU;
* энергопотребление;
* задержку inference;
* размер модели;
* FPS;
* время запуска;
* работу с камерами в режиме реального времени.

Использую подходы:

* **ONNX**
* **TensorRT**
* **FP16 / INT8**
* оптимизация моделей;
* уменьшение размера моделей;
* ускорение inference;
* batch / dynamic shapes;
* профилирование производительности;
* запуск моделей на ARM и NVIDIA-платформах.

Основные платформы:

**Raspberry Pi · NVIDIA Jetson · NVIDIA GPU · Arduino / микроконтроллеры**
